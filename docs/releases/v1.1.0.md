Run the complete game with Docker, or try the [browser demo](https://rojerm2.github.io/jack-en-poy-ai/).
The browser demo includes local gameplay and animation; trained inference is available through Docker.

### Changes

- Added a three-service Docker Compose stack with health checks, private API/inference ports, non-root
  containers, writable data volumes and proxy request limits.
- Added a backend-free GitHub Pages demo and explicit demo/strategy labels.
- Fixed repeated wrong counters for unchanged player history. Repeated rock now gets a paper counter;
  paper and scissors get their corresponding counters. Rule statistics remain separate from ML.
- Updated Spring Boot to 4.1.1, added graceful shutdown, pinned CI actions and documented operations.
- Added MIT licensing, contribution/security guidance and release checksums.

### Run

```sh
git clone --branch v1.1.0 https://github.com/rojerm2/jack-en-poy-ai.git
cd jack-en-poy-ai
docker compose up --build --detach --wait
```

Open http://localhost:8088. Stop with `docker compose stop`.

### Downloads

- `jack-en-poy-ai-1.1.0.jar`: packaged game API; requires Java 21.
- `jack-en-poy-browser-demo-1.1.0.zip`: static browser demo, application license and dependency notices.
- `jack-en-poy-ml-1.1.0.zip`: Python service/CLI source, pinned dependencies and a compatible sample model.
- `SHA256SUMS.txt`: checksums for the three artifacts.

### Validation and limits

Validation includes 35 Python tests, 30 Java tests, 21 frontend tests, two Chromium browser tests,
real-service integration and Docker build/gameplay/restart checks in GitHub Actions. The complete game supports one backend instance;
session scores reset on Java restart while CSV/model/report volumes persist. The model uses a small
sample and does not train during play. The public demo has no backend or trained inference.
See the README and deployment guide for details.
