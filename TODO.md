# Future work

The 1.1.0 release includes Docker deployment, a standalone browser demo and the complete game.
No backend hosting service is planned for the public demo.

- Evaluate a larger independent multi-player dataset and calibrate classifier confidence.
- Add persistent/shared session storage before supporting multiple backend instances.
- Add request deduplication for retries after a lost HTTP response.
- Explore personalized models and drift monitoring with explicit evaluation.
